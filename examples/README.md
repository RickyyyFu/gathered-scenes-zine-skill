# 作品档案 · Scene Archive

**作者 / Author：zeejay**

这里用于保存拾景纸刊的精选案例。每个案例不是单独的一张结果图，而是一份简短的场景档案。

## 档案内容

```text
scene-001/
├── source.jpg       # 获得公开许可的原始照片
├── result.jpg       # 最终纸刊作品
└── README.md        # 观察记录与创作说明
```

每份观察记录建议包含：

- 场景标题与编号
- 使用的 Skill 与版本
- 核心主体和关键空间关系
- 被保留、压缩、舍弃和转译的内容
- 色彩结构与构图选择
- 一句简短的创作说明
